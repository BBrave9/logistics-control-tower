\# Torre de Controle Logística



\## Descrição



Projeto de analytics desenvolvido em Tableau para monitoramento de desempenho logístico, regional e de vendedores.



\## Abas



\- Visão Geral

\- Performance Regional

\- Performance de Vendedores



\## Fonte de dados



analytics.fct\_logistics\_orders



\## Principais métricas



\- Total de pedidos

\- Pedidos entregues

\- Pedidos em aberto

\- Taxa de atraso

\- Tempo médio de entrega

\- Frete médio

\- Frete em risco

\- Performance regional

\- Performance de vendedores



\## Estrutura do projeto



\- docs/: documentação

\- tableau/: arquivos do Tableau

\- sql/: scripts de validação

\- assets/: imagens e elementos visuais

\- tests/: evidências e checklists
